# Triage Labels

The engineering workflow uses these canonical triage labels in this repository:

| Role | Label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Maintainer needs to evaluate the issue |
| Needs information | `needs-info` | Waiting for actionable reporter information |
| Ready for agent | `ready-for-agent` | Fully specified and ready for implementation |
| Ready for human | `ready-for-human` | Requires human judgment or implementation |
| Won't fix | `wontfix` | Will not be actioned |
